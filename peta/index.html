Peta Hierarki & Jejaring Hukum

Tata hukum Indonesia berjenjang — setiap peraturan menautkan keabsahannya ke norma di atasnya lewat konsideran "Mengingat" (teori jenjang norma Stufenbau Kelsen–Merkl; hierarki resmi: Pasal 7–8 UU 12/2011). Pita di bawah menyusun 111 karya korpus per jenjang; 92 karya menunjuk langsung ke UUD 1945. Arahkan kursor ke sebuah peraturan untuk menyorot jejaringnya; klik untuk membaca (69 karya sudah berteks lengkap).
dasar hukum ("Mengingat") mengubah mencabut (sebagian) putusan MK (uji materi) teks lengkap kodifikasi baru metadata
Kelompok garis dibuat redup agar pita tetap terbaca — sorot simpul untuk melihat relasinya (fokus + konteks, praktik lazim visualisasi graf ketergantungan). Putusan MK bukan peraturan perundang-undangan, maka ditempatkan sebagai lajur tersendiri; amarnya menempel sebagai anotasi pada pasal yang diuji. Data graf: API JSON.
